# SHADOW AI

Browser-based local AI using WebLLM.

## Install

npm install

## Run

npm run dev

## Build

npm run build

## Deploy

Push this project to GitHub.

Import the repository into Vercel.

Or use:

npm install -g vercel
vercel
vercel --prod

No API key required.

Requires a WebGPU-compatible browser.
Models download on first use.
